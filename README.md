# CityChat

La tua citta al sicuro — segnalazioni, mappa e chat pubblica in tempo reale.

## Deploy
Sito statico: `index.html` e la root.

## Supabase
Esegui lo schema SQL (commento in fondo a `index.html`) nel SQL Editor del progetto collegato in `SB_CONFIG`.
Abilita Realtime su `citychat_reports` e `citychat_messages`.
